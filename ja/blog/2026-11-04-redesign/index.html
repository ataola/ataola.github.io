サイトを作り直す——「玩具」から「自分の場所」へ

郑江涛 · 2026-11-04 · 2 分 · 建站 / 设计

旧サイトは並列のルートと入口の関門だけで、「今なにをしているか」を答える場所がなかった。今回はブログとして作り直した。

この記事は現在中国語のみです。

旧站的代码我留了五年。Vue 3 刚发布那会儿写的，rem 布局、粒子背景、自动播放的背景音乐，还有一个必须先点掉的引导页——现在回头看，那些都是「炫技」，不是「作品」。

它最大的问题跟好不好看无关：没有一个地方在回答问题。二十个路由平铺：导航、福利、专题、实验室、地图、图表、纪念页。每个都能进，但没有一个告诉访客：这个人现在在做什么。

新的结构

这次只留五个入口：

  • 首页：一段定位 + 现在在做什么 + 服务矩阵 + 最近文章
  • 文章：Markdown 写作，按年归档，标签筛选
  • 项目：服务清单，标注「公开 / 需登录 / 仅内网」
  • 实验室：旧站的彩蛋全部收进这里，不占主导航
  • 关于：我是谁、技术栈、时间线

彩蛋留着，只是降级。木鱼还是那个木鱼，但它不该和「文章」并排站在一起。

视觉上的取舍

浅色、衬线标题、细横线、大留白。中文不加载 webfont——Noto Serif SC 一个字重就要几 MB，用系统衬线兜底，首屏零字体请求。

强调色只留一个：朱红 #b23a2f。用在链接、当前项、时间线的年份上，别的地方一律墨黑。

:root {
  --paper: #faf8f5;
  --ink: #1c1a17;
  --accent: #b23a2f;
  --measure: 68ch;
}

深色模式不单独做主题切换，跟系统走。少一个按钮，少一个状态。

技术上做了什么减法

  • 去掉粒子、音乐、vue-fullpage、fontawesome、pinia（这站没有需要跨页共享的状态）
  • Markdown 用 markdown-it + highlight.js，按需注册 8 种语言，不打全量包
  • 路由改 history 模式，配 404.html 回退；同一个 base 变量同时支持根域和 /hub/site-preview/ 子目录预览
  • ECharts 和地图页全部懒加载，首页只加载 60KB 左右的 JS

还没做完的

地图页依赖百度地图 AK，暂时下线；实验室里标了「暂不可用」，等哪天想起来再补。

写作流也在试：文章直接写在 src/content/posts/*.md，frontmatter 只有 title / date / summary / tags。够用。
